Install

Copy Desk is a folder.

You put it where your AI looks for skills, tell it who you are and who your clients are, and it renders your first desk. There is no account and no server. Everything it writes stays on your machine as markdown.

  1. Install the plugin

    Pick the one that matches how you work. All three install the same folder, and everything released so far comes with it: the blog pack and the templates for writing your own. Industry packs install the same way when they ship: a pack is a folder you drop into packs/.

    Claude Code. From any project:

    # add the marketplace once, then install
/plugin marketplace add jakovskyy/skills
/plugin install copydesk

    Claude Cowork and claude.ai. Download the plugin from the Source link above and add it under Settings, Capabilities, Plugins. Claude loads it when a client, a sweep or a campaign comes up.

    Codex, OpenClaw and any agent that reads SKILL.md. Copy the copydesk folder into wherever your agent keeps its skills. You get the skills. The slash commands are Claude-specific and will not appear, so you ask in plain words instead.

  2. Run setup once

    Say /copydesk setup, or just "set up my copy desk." It asks ten questions from Campaign Architect's house-rules template: what you do, who you work for, the words you never use, who approves what. It writes ~/copydesk/copydesk.md from the answers. Ten minutes, and it never asks again.

  3. Add a client

    /copydesk client sendwell, or "add a client called Sendwell." It creates the folder, writes the client's house-rules.md from a short intake, and starts the client on the blog pack. When industry packs ship, a client declares them in house-rules.md. Point it at the client's live site and it seeds the upkeep log with every page it can find.

    ~/copydesk/
├── copydesk.md            who you are, your packs, your model tiers
├── clients/
│   └── sendwell/
│       ├── house-rules.md
│       ├── brand/           voice.md · words.md · claims.md
│       ├── upkeep/          one file per published piece
│       ├── pipeline.md
│       ├── campaigns/       one file per brief
│       ├── schedule.md
│       └── programs/
└── desk.html              rendered, regenerate any time

  4. Render the desk

    /copydesk, or "show me the desk." It reads every file, renders desk.html, and opens it. The ribbon at the top says how many files it read and when. Nothing is sent anywhere. Close it, edit any file by hand, render again.

  5. Let the agents work

    "Run the fact sweep on Sendwell" has the upkeep agent check every figure, date and SEO field on every live piece against the facts file, and flag what changed. "Rules pass on Sendwell" has it reread the pieces against the words, claims and register rules. "Brief a campaign to get more trial stores printing a first label" hands the question to Campaign Architect. Each run tells you which model tier it wants before it starts, and nothing is changed until you approve it.

Questions

Before you install.

Does anything leave my machine? No. The plugin is files. Your AI reads them and writes them. The only network traffic is whatever your AI already does to answer you.

What does it cost? Nothing. The plugin, the blog pack and the pack templates are free and open source. Some future industry packs may be paid. The desk itself will not be.

Can I use it with clients in different industries? Yes. Each client folder declares its own packs. A brokerage and a SaaS company sit side by side in the same desk.

What if I do not use Claude? The skills work in any agent that reads SKILL.md. The slash commands do not. The dashboard renders the same either way.

Can I edit the files by hand? That is the point. They are markdown. Edit them in anything and render again.
